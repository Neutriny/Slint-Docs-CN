## Vim

要安装 Slint Language Server，请查看 <Link type="SlintLSP" label="LSP 文档"/>。

Vim 通过其 [Conquer of Completion](https://github.com/neoclide/coc.nvim)
插件支持 Language Server Protocol。结合 Slint LSP 服务器，这可以在编辑 `.slint` 文件时提供内联诊断和代码补全。

安装扩展后（例如通过 [vim-plug](https://github.com/junegunn/vim-plug)），
还需要进行两处额外的配置更改，才能将 LSP 服务器与 vim 集成：

1. 让 vim 以正确的文件类型识别 `.slint` 文件

安装 [`slint-ui/vim-slint`](https://github.com/slint-ui/vim-slint) 插件。

或者，你可以将以下内容添加到你的 vim 配置文件（例如 `vimrc`）中，
以启用对 `.slint` 文件的自动识别：

{/* cSpell: disable */}

```
autocmd BufEnter *.slint :setlocal filetype=slint
```

{/* cSpell: enable */}

2. 确保 slint 语言服务器已安装并能在 PATH 中找到。

3. 配置 Conquer of Completion 以使用 Slint LSP 服务器

启动 `vim` 并运行 `:CocConfig` 命令，调出允许编辑
JSON 配置文件（`coc-settings.json`）的缓冲区，并确保在 `language` 服务器部分下存在以下映射：

```json
{
  "languageserver": {
    "slint": {
      "command": "slint-lsp",
      "filetypes": ["slint"]
    }
  }
}
```

## Neovim

按照 Vim 部分的第 1 步操作，即可获得对 `.slint` 文件的支持。

在 Neovim 中使用该语言服务器最简单的方式是通过 [`neovim/nvim-lspconfig`](https://github.com/neovim/nvim-lspconfig) 插件。

要安装该语言服务器，你可以：

- <Link type="SlintLSP" label="手动安装并配置" />
- 安装 [Mason](https://github.com/mason-org/mason.nvim) 并运行 `:MasonInstall slint-lsp`（在 Windows、Linux 和 macOS 上）

### 实时预览

`slint-lsp` 语言服务器安装并运行后，你可以打开实时预览：
将光标放在组件名称上并触发代码操作（默认绑定到 `gra`）。
根据你的配置，此操作可能绑定到其他按键，因此请检查你的配置以找到合适的按键绑定（`vim.lsp.buf.code_action()`）。

你可能还想安装一个用于指示代码操作何时可用的插件，例如 [kosayoda/nvim-lightbulb](https://github.com/kosayoda/nvim-lightbulb)。

#### 从 Neovim 高亮元素

要直接从 Neovim 高亮实时预览中的元素，可以：
使用 "hover" LSP 操作（默认 `K`），或启用 [document-highlight](<https://neovim.io/doc/user/lsp/#vim.lsp.buf.document_highlight()>) 特性。
启用文档高亮后，将光标移到某个元素上会自动在实时预览中高亮它，将光标移开则会移除高亮。

:::tip[个人建议]
[akioweh/lsp-document-highlight](https://github.com/akioweh/lsp-document-highlight.nvim) 插件提供了一种简单的方式来配置 document-highlight 操作，而不会产生默认配置会造成的闪烁。
:::

### Tree-sitter

如果你使用 `nvim-treesitter`，可以使用 `TSInstall slint` 安装 Slint 的 Tree Sitter 解析器，
以获得语法高亮和缩进支持。
