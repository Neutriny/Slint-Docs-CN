## 属性

### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
如果 enabled 为 false，则无法与滑块交互。
</SlintProperty>

### has-focus
<SlintProperty propName="has-focus" typeName="bool" propertyVisibility="out">
当滑块当前具有焦点时设置为 true
</SlintProperty>

### value
<SlintProperty propName="value" typeName="float" defaultValue="0" propertyVisibility="in-out">
值。默认为最小值。
```slint "value: 50;"
Slider {
    value: 50;
}
````

</SlintProperty>

### step

<SlintProperty propName="step" typeName="float" defaultValue="1">
按下方向键时的变化步长。
```slint "step: 1;"
Slider {
    step: 1;
}
```
</SlintProperty>

### minimum

<SlintProperty propName="minimum" typeName="float" defaultValue="0">
最小值。
```slint "minimum: 10;"
Slider {
    minimum: 10;
    value: 11;
}
```
</SlintProperty>

### maximum

<SlintProperty propName="maximum" typeName="float" defaultValue="100">
最大值。
```slint "maximum: 10;"
Slider {
    maximum: 10;
    value: 9;
}
```
</SlintProperty>

### orientation

<SlintProperty
  propName="orientation"
  typeName="enum"
  enumName="Orientation"
  defaultValue="horizontal"
>
  描述 Slider 的方向，垂直或水平。
</SlintProperty>

## 回调

### changed(float)

值发生了改变

```slint {2-4}
Slider {
    changed(value) => {
        debug("New value: ", value);
    }
}
```

### released(float)

当用户完成更改滑块的值时调用，即在旋钮上的按压被释放或方向键被松开时。

```slint {2-4}
Slider {
    released(position) => {
        debug("Released at position: ", position);
    }
}
```
