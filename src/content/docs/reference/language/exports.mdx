<SC>
## 位置

`export` 语句可以出现在 `.slint` 源文件的顶层，与[组件定义](../file-structure/#sls.file.component.definition-forms)交错。 \{#sls.export.placement}

## 私有性

默认情况下，在 `.slint` 源文件中定义的名字对该文件是私有的。
只有当名字被显式导出时，导入者才能看到它。 \{#sls.export.default-private}

## 形式

`export` 语句具有以下形式之一： \{#sls.export.forms}

```slint no-test
export component Name { /* ... */ }
export { Name, ... }
```

## 在声明处导出

形式 `export component Name { ... }` 在单条语句中定义组件并导出它。
导出的名字就是组件自身的名字。 \{#sls.export.declaration-site}

## 导出列表

形式 `export { Name, ... }` 导出当前文件中已定义的一个或多个名字。
允许尾随逗号。 \{#sls.export.list}

导出列表项要么是裸标识符 `Name`，要么是 `Name as Other` 形式的改名。
改名会以对外名字 `Other` 导出本地定义的 `Name`。
本地名字 `Name` 仍保留在当前文件中定义。 \{#sls.export.rename}

`as` 左侧的每个标识符，以及每个裸标识符，都应指向当前文件中定义的名字。 \{#sls.export.left-must-exist}

## 重复导出

源文件不得多次导出同一个对外名字。
这包括在声明处导出与导出列表项的任何组合。 \{#sls.export.no-duplicates}

</SC>

带 `from` 子句的 export 语句会[重新导出](../imports/#re-exports)另一个文件中的声明。
除了组件之外，还可以导出[结构体、枚举](../structs-and-enums/)以及[全局对象](../globals/)。
