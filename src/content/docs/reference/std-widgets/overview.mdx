```slint playground
import { Palette, HorizontalBox } from "std-widgets.slint";

export component MyCustomWidget {
    in property <string> text <=> label.text;

    Rectangle {
        background: Palette.control-background;

        HorizontalBox {
            label := Text {
                color: Palette.control-foreground;
            }
        }
    }
}
```

Slint 提供了一系列可从 `"std-widgets.slint"` 导入的内置控件。

控件外观取决于所选的样式。
有关如何选择样式以及如何使用 `Palette` 和 `StyleMetrics` 属性的详细信息，请参阅 <Link type="StyleWidgets" label="选择控件样式"/>。如果未选择样式，则 `fluent` 是所有平台上的默认样式。

所有控件都支持所有 <Link type="CommonProperties" label="内置元素通用的属性"/>。
