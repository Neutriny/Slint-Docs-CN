<SC>
绑定将[表达式](../expressions/)赋给其所在元素体内某个[属性](../properties/#sls.prop.def)。
它的形式为属性名，后跟 `:`、一个表达式以及 `;`。 \{#sls.binding.form}

```slint
export component Example inherits Window {
    Rectangle {
        background: #2a6e3f;
    }
}
```

该名字应指向外层元素的一个属性。 \{#sls.binding.target-must-exist}

当表达式类型不是属性类型时，只有在存在适用转换的情况下才能绑定到该属性。 \{#sls.type.conversions}

表达式的类型应是属性的类型，或可[转换](#sls.type.conversions)为该类型。 \{#sls.binding.type}

设置属性会用所设置的值替换其绑定。 \{#sls.binding.set-replaces}

</SC>

绑定也可以包含一个[代码块](../statements/)，
而 [`<=>` 运算符](../two-way-bindings/)会链接两个属性。
