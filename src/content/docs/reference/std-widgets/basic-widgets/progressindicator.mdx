`ProgressIndicator` 向用户告知正在进行操作的进度状态，例如从网络加载数据。

## 属性

### indeterminate

<SlintProperty propName="indeterminate" typeName="bool" defaultValue="false">
  如果无法通过值确定操作的进度，则设置为 true。
</SlintProperty>

### progress

<SlintProperty propName="progress" typeName="float" defaultValue="0">
完成百分比，为 0 到 1 之间的值。小于 0 或大于 1 的值将被限制。
```slint "progress: 0.5;"
ProgressIndicator {
    progress: 0.5;
}
```
</SlintProperty>
