要安装 Slint Language Server，请查看 <Link type="SlintLSP" label="LSP 文档"/>。

要设置 LSP：

1. 确保 slint language server 已安装
2. 使用 Sublime Text 中的 Package Control 安装 LSP 包（[sublimelsp/LSP](https://github.com/sublimelsp/LSP)）
3. 将 Slint 语法高亮文件下载到你的 User Package 文件夹中，
   例如在 macOS 上为 `~/Library/Application Support/Sublime Text/Packages/User/`：
   https://raw.githubusercontent.com/slint-ui/slint/master/editors/sublime/Slint.sublime-syntax
   https://raw.githubusercontent.com/slint-ui/slint/master/editors/sublime/Slint.tmPreferences
4. 将 LSP 包设置文件下载到你的 User Package 文件夹中：
   https://raw.githubusercontent.com/slint-ui/slint/master/editors/sublime/LSP.sublime-settings
5. 修改 `LSP.sublime-settings` 中的 slint-lsp 命令路径，使其指向你主目录中的 cargo 安装路径（**将 YOUR_USER 替换为你的用户名**）：
   `"command": ["/home/YOUR_USER/.cargo/bin/slint-lsp"]`
6. 从 Sublime 的命令面板运行 "LSP: Enable Language Server Globally" 或 "LSP: Enable Language Server in Project"，以允许服务器启动。
7. 打开一个 .slint 文件 - 如果服务器启动，其名称会显示在状态栏的左侧。

### 实时预览

要**预览组件**，请在打开 .slint 文件时，将光标放在
你想预览的组件名称上，然后选择会
出现在编辑器窗格右侧的 "Show preview" 按钮。
