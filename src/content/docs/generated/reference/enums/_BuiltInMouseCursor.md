The following built-in mouse cursor shapes are available through the
`MouseCursor` namespace. The upstream Slint documentation generator emits this
table; this port does not ship the generator, so the table below is a
hand-maintained stub.

| Cursor                                             | Description                    |
| -------------------------------------------------- | ------------------------------ |
| `MouseCursor.default`                              | The platform default cursor    |
| `MouseCursor.none`                                 | Hide the cursor                |
| `MouseCursor.help`                                 | Help / question mark           |
| `MouseCursor.pointer`                              | Pointing hand                  |
| `MouseCursor.progress`                             | Busy, still interactive        |
| `MouseCursor.wait`                                 | Busy                           |
| `MouseCursor.crosshair`                            | Crosshair                      |
| `MouseCursor.text`                                 | Text selection                 |
| `MouseCursor.move`                                 | Move                           |
| `MouseCursor.grab`                                 | Grab                           |
| `MouseCursor.grabbing`                             | Grabbing                       |
| `MouseCursor.n-resize` … `MouseCursor.nwse-resize` | Edge and corner resize cursors |
