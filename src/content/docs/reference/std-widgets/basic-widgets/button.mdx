import SlintProperty from '@slint/common-files/src/components/SlintProperty.astro';
import Link from '@slint/common-files/src/components/Link.astro';

```slint playground
import { Button, VerticalBox } from "std-widgets.slint";
export component Example inherits Window {
    width: 200px;
    height: 100px;
    VerticalBox {
        label := Text {
            text: "Button not clicked";
        }
        Button {
            text: "Click Me";
            clicked => {
                label.text = " Button clicked";
            }
        }
    }
}
```

一个简单的按钮。常见的按钮类型也可以通过 <Link type="StandardButton" /> 创建。

## 属性

### checkable

<SlintProperty propName="checkable" typeName="bool" defaultValue="false">
显示按钮是否可选中。这使 `checked` 属性有可能变为 true。

```slint "checkable: true;"
Button {
    text: "Checkable Button";
    checkable: true;
}
```

</SlintProperty>

### checked

<SlintProperty
  propName="checked"
  typeName="bool"
  defaultValue="false"
  propertyVisibility="in-out"
>
  显示按钮是否已选中。需要 `checkable` 为 true 才能生效。
</SlintProperty>

### enabled

<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
  默认为 true。当为 false 时，按钮无法被按下。
</SlintProperty>

### has-focus

<SlintProperty propName="has-focus" typeName="bool" propertyVisibility="out">
  当按钮具有键盘焦点时设置为 true
</SlintProperty>

### icon

<SlintProperty propName="icon" typeName="image">
  在按钮中显示的图片。请注意，并非所有样式都支持绘制图标。
</SlintProperty>

### icon-size

<SlintProperty propName="icon-size" typeName="length">
  按钮中显示的图标大小。默认值取决于样式。如果需要容纳较大的图标尺寸，按钮将自动增大。
</SlintProperty>

### pressed

<SlintProperty propName="pressed" typeName="bool" propertyVisibility="out">
  当按钮被按下时设置为 true。
</SlintProperty>

### text

<SlintProperty propName="text" typeName="string">
按钮中显示的文本。

```slint 'text: "Button with text";'
Button {
    text: "Button with text";
}
```

</SlintProperty>

### primary

<SlintProperty propName="primary" typeName="bool" defaultValue="false">
  如果设置为 true，按钮将使用主强调色显示。
</SlintProperty>

### colorize-icon

<SlintProperty propName="colorize-icon" typeName="bool" defaultValue="false">
  如果设置为 true，图标将被着色为与 Button 文本颜色相同的颜色。
</SlintProperty>

## 回调

### clicked()

在以下情况调用：手指或鼠标左键在此元素上按下，然后释放。

```slint {3-5}
Button {
    text: "Click me";
    clicked() => {
        debug("Button clicked");
    }
}
```
