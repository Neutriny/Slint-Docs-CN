本页精选了一些可用于 Slint 开发的第三方库和附加组件。

如果你有认为应该列在这里的库，请在我们的 [Bug tracker](https://github.com/slint-ui/slint/issues) 上告诉我们，
或者为[本页](https://github.com/slint-ui/slint/blob/master/docs/astro/src/content/docs/guide/development/third-party-libraries.mdx)提交一个 pull request。

## 组件集

### Material

[Material 组件集](https://material.slint.dev/) 是一组基于 [Material Design 3 规范](https://m3.material.io/) 的组件。

它是一组可用于构建 Material Design 3 应用的组件。

该组件集在 Slint 仓库的[这个文件夹](https://github.com/slint-ui/slint/tree/master/ui-libraries/material)中开发。

https://material.slint.dev/

### SurrealismUI

[SurrealismUI](https://github.com/Surrealism-All/SurrealismUI) 是一个使用 Slint 的第三方 UI 库

https://github.com/Surrealism-All/SurrealismUI

### Vivi

[Vivi](https://app.radicle.xyz/nodes/seed.radicle.garden/rad:z3oxAZSLcyXgpa7fcvgtueF49jHpH) 是一个面向 Slint 的第三方
自定义组件库。
该项目的目标是提供一整套组件，用于创建从小型应用到复杂桌面应用的各种用户界面。

https://app.radicle.xyz/nodes/seed.radicle.garden/rad:z3oxAZSLcyXgpa7fcvgtueF49jHpH

### Sleek-ui

[Sleek-ui](https://github.com/uAtomicBoolean/sleek-ui) 是一个第三方 UI 组件库，
基于 [ant design](https://ant.design) 使用 Slint 构建/为 Slint 构建。

https://github.com/uAtomicBoolean/sleek-ui/

## 模板

### Heng30 的 Slint 模板

这是一个面向 Slint GUI 的 Rust 模板项目。
它包含常用组件、设置面板、配置、简易数据库功能以及其他小功能。
该项目可以编译到桌面（Windows、Linux、Macos）、Android 和 Web 平台。

https://github.com/heng30/slint-template
