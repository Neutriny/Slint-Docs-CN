在对单张牌建模之后，这一步将创建由这些牌组成的网格。要让网格成为游戏棋盘，你需要两个特性：

1. **数据模型**：在代码中作为模型创建的数组，其中每个元素描述牌的数据结构，例如：

   - 图像的 URL
   - 图像是否可见
   - 玩家是否已解开这张牌。

2. 创建牌的多实例的方式。

在 Slint 中，你使用方括号声明一个基于模型的结构体数组。使用 <span class="hljs-keyword">for</span> 循环
来创建同一元素的多个实例。

<span class="hljs-keyword">for</span> 循环是声明式的，并会在
模型变化时自动更新。该循环会实例化所有
<span class="hljs-title">MemoryTile</span> 元素，并根据它们的
索引将它们放置到网格上，牌与牌之间留有间距。

首先，在 `ui/app-window.slint` 文件顶部添加牌的数据结构定义：

<code>

  <span class="hljs-keyword">in</span> memory_tiles:
</code>
语法声明了一个变量 `tile`，它包含来自 `memory_tiles` 数组的一个元素的数据，
还声明了一个变量 `i`，即牌的索引。代码使用 `i`
索引，根据牌所在的行和列来计算其位置， 使用取模和整数除法来创建 4×4 网格。
