:::note[Note]
在开发 iOS 的 Slint 应用程序时，你只能使用 Rust 作为编程语言。
:::

基于 Rust 的 Slint 应用程序可以交叉编译到 iOS，并在 iPhone、iPad 及其各自的
模拟器上运行。这是通过 <Link type="WinitBackend" label="Winit 后端" /> 和

<Link type="skia_renderer" label="Skia 渲染器" /> 实现的。

## 先决条件

- 一台运行 macOS 的电脑。
- 最新安装的 [Xcode](https://developer.apple.com/xcode/)。
- [Xcodegen](https://github.com/yonaskolb/XcodeGen?tab=readme-ov-file#installing)。
- [Rust](https://rustup.rs)
- Rust 设备端和模拟器工具链。运行 `rustup target add aarch64-apple-ios` 和 `rustup target add aarch64-apple-ios-sim`
  来添加它们。

## 为现有的 Rust 应用程序添加 iOS 支持

以下步骤假设你已经准备好一个使用 Slint 的 Rust 应用程序。如果你刚入门，请使用我们的 [Slint Rust Template](https://github.com/slint-ui/slint-rust-template)
让一个最小应用跑起来。

使用 XCode 构建、部署 iOS 应用程序并提交到 App Store。
使用 [Xcodegen](https://github.com/yonaskolb/XcodeGen) 从一份最简描述创建 Xcode 项目。

1. 通过运行以下命令，验证你的应用程序能为 iOS 编译：

```bash
cargo build --target=aarch64-apple-ios
```

2. 创建一个名为 `project.yml` 的文件，内容如下：

```yml
name: My App
options:
  bundleIdPrefix: com.company
settings:
  ENABLE_USER_SCRIPT_SANDBOXING: NO
targets:
  MyApp:
    type: application
    platform: iOS
    deploymentTarget: '13.0'
    info:
      path: Info.plist
      properties:
        CADisableMinimumFrameDurationOnPhone: true
        UILaunchScreen:
          - ImageRespectSafeAreaInsets: false
        UIApplicationSceneManifest:
          UIApplicationSupportsMultipleScenes: false
          UISceneConfigurations:
            UIWindowSceneSessionRoleApplication:
              - UISceneConfigurationName: Slint
                UISceneDelegateClassName: SlintWindowSceneDelegate
    sources: []
    postCompileScripts:
      - script: |
          ./build_for_ios_with_cargo.bash slint-rust-template
        outputFileLists: $TARGET_BUILD_DIR/$EXECUTABLE_PATH
```

根据需要调整名称、bundle id 和其他字段。

这个配置文件通过一个 shell 脚本把构建过程委托给 cargo。

`CADisableMinimumFrameDurationOnPhone` 条目让动画以屏幕的
完整刷新率运行。
没有它，即使 ProMotion 显示屏支持 120，iOS 也会把 iPhone 应用限制在每秒 60 帧。
iPad 不受影响。

`UIApplicationSceneManifest` 条目让应用选择使用 UIKit 的场景生命周期，
这是 iOS 27 所要求的：没有它的应用会启动失败。
`SlintWindowSceneDelegate` 是 Slint 的 winit 后端提供的场景委托，
它把 Slint 的窗口附加到 UIKit 所连接的场景。
保持该条目原样。
关于此要求的背景，请参见 Apple 的
[TN3187](https://developer.apple.com/documentation/technotes/tn3187-migrating-to-the-uikit-scene-based-life-cycle)。

:::note[Note]
该 shell 脚本以 cargo 生成的二进制文件名被调用。请更新它以匹配你的项目名称。
:::
