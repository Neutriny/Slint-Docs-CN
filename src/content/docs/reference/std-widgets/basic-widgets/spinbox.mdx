## 属性

### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
如果 enabled 为 false，则无法与微调框交互。
</SlintProperty>

### has-focus
<SlintProperty propName="has-focus" typeName="bool" propertyVisibility="out">
当微调框当前具有焦点时设置为 true。
</SlintProperty>

### value
<SlintProperty propName="value" typeName="int" defaultValue="0" propertyVisibility="in-out">
值。默认为最小值。
```slint "value: 50;"
SpinBox {
    value: 50;
}
````

</SlintProperty>

### minimum

<SlintProperty propName="minimum" typeName="int" defaultValue="0">
最小值。
```slint "minimum: 10;"
SpinBox {
    minimum: 10;
    value: 11;
}
```
</SlintProperty>

### maximum

<SlintProperty propName="maximum" typeName="int" defaultValue="100">
最大值。
```slint "maximum: 10;"
SpinBox {
    maximum: 10;
    value: 9;
}
```
</SlintProperty>

### read-only

<SlintProperty propName="read-only" typeName="bool" defaultValue="false">
  如果为 true，用户无法修改值。
</SlintProperty>

### step-size

<SlintProperty propName="step-size" typeName="int" defaultValue="1">
  递增或递减 `value` 时使用的步长。
</SlintProperty>

### horizontal-alignment

<SlintProperty
  propName="horizontal-alignment"
  typeName="enum"
  enumName="TextHorizontalAlignment"
  defaultValue="left"
>
  文本的水平对齐方式。
</SlintProperty>

## 回调

### edited(int)

当值因用户修改而发生变化时发出

```slint {2-4}
SpinBox {
    edited(value) => {
        debug("New value: ", value);
    }
}
```
