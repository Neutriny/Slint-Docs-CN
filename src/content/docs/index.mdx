### 文档特性

文档中包含大量代码片段。语言提示会标明片段使用的语言。

<div style="display: flex; justify-content: left;">
  <Image
    src={LanguageHint}
    style={{ width: '500px' }}
    alt="文档中语言提示的截图"
  />
</div>

部分 Slint 代码片段是交互式的。可点击`run`按钮，在名为 [SlintPad](https://slintpad.com) 的网页端实时编辑工具中运行片段。

<div style="display: flex; justify-content: left;">
  <Image
    src={RunInSlintPad}
    style={{ width: '500px' }}
    alt="显示 run 按钮的截图"
  />
</div>

可以使用复制按钮轻松复制片段内容。

<div style="display: flex; justify-content: left;">
  <Image
    src={CopySnippet}
    style={{ width: '500px' }}
    alt="显示复制按钮的截图"
  />
</div>

为了让示例聚焦代码的特定部分，会出现高亮。这是文档所独有的特性，你在自己写的代码里不会看到这类高亮。
