`StandardTableView` 表示一个由列和行组成的数据表格。列由
`columns` 属性定义，每一行是通过 `rows` 属性设置的
`StandardListViewItem` 模型。

<CodeSnippetMD imagePath="/src/assets/generated/std-widgets-standardtableview.png"  imageWidth="200" imageHeight="200"  imageAlt='std-widgets standardtableview example'>
```slint playground
import { StandardTableView } from "std-widgets.slint";
export component Example inherits Window {
    width: 230px;
    height: 200px;

    StandardTableView {
        width: 230px;
        height: 200px;
        columns: [
            { title: "Header 1" },
            { title: "Header 2" },
        ];
        rows: [
            [
                { text: "Item 1" }, { text: "Item 2" },
            ],
            [
                { text: "Item 1" }, { text: "Item 2" },
            ],
            [
                { text: "Item 1" }, { text: "Item 2" },
            ]
        ];
    }

}

````
</CodeSnippetMD>



## 属性

与 <Link type="ScrollView" /> 相同的滚动属性，另外还有：

### current-sort-column
<SlintProperty typeName="int" propName="current-sort-column" propertyVisibility="out">
指示已排序的列，当没有列被排序时为 `-1`。
</SlintProperty>

### columns
<SlintProperty typeName="[struct]" structName="TableColumn" propName="columns" defaultValue="[]" propertyVisibility="in-out">
定义表格列的模型。

```slint 'columns: [{ title: "Header 1" }, { title: "Header 2" }];'
StandardTableView {
    columns: [{ title: "Header 1" }, { title: "Header 2" }];
    rows: [[{ text: "Item 1" }, { text: "Item 2" }]];
}
````

</SlintProperty>

### rows

<SlintProperty typeName="[[struct]]" structName="StandardListViewItem" propName="rows" defaultValue="[]" propertyVisibility="in-out">
定义表格行的模型。

```slint 'rows: [[{ text: "Item 1" }, { text: "Item 2" }]];'
StandardTableView {
    columns: [{ title: "Header 1" }, { title: "Header 2" }];
    rows: [[{ text: "Item 1" }, { text: "Item 2" }]];
}
```

</SlintProperty>

### current-row

<SlintProperty
  typeName="int"
  propName="current-row"
  defaultValue="-1"
  propertyVisibility="in-out"
>
  当前活动行的索引。-1 表示未选中任何行，这是 默认值。
</SlintProperty>

## 回调

### sort-ascending(int)

如果应按给定列以升序对模型排序，则发出。

### sort-descending(int)

如果应按给定列以降序对模型排序，则发出。

### row-pointer-event(int, PointerEvent, Point)

在任何鼠标指针事件上发出，类似于 `TouchArea`。参数为与该事件关联的行索引、`PointerEvent` 本身以及 tableview 内的鼠标位置。

### current-row-changed(int)

当当前行因用户修改而发生变化时发出

```slint {5-7}
StandardTableView {
    columns: [{ title: "Header 1" }, { title: "Header 2" }];
    rows: [[{ text: "Item 1" }, { text: "Item 2" }]];

    current-row-changed(index) => {
        debug("Current row: ", index);
    }
}
```

## 函数

### set-current-row(int)

通过索引设置当前行，并将其滚动到可见区域。
