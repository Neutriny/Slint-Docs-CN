[Zed](https://zed.dev) 是一款高性能的多人在线代码编辑器。[zed-slint 扩展](https://github.com/slint-ui/slint/tree/master/editors/zed)最初由 Luke Jones 开发并捐赠，现在归 slint 组织所有。它将 <Link type="SlintLSP" label="slint language server"/> 的最新版本集成到 Zed 中，提供代码补全和语法高亮。通过以下步骤安装该扩展：

1. 通过 Zed -> Extensions 菜单打开扩展选项卡。
2. 在搜索字段中输入 "slint"。
3. 点击 "Slint" 扩展的 "Install"。

### 实时预览

扩展安装后，你可以直接从编辑器预览组件。
将光标放在组件名称上（例如
`component MainWindow inherits Window {` 中的 `MainWindow`），然后触发语言服务器
提供的 _Show Preview_ 代码操作。
