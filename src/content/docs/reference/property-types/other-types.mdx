## 键盘输入

<a id="keys"></a>

### keys

<SlintProperty propName="keys" typeName="keys" defaultValue='empty keys'>
keys 表示一个键与修饰键列表的组合。
这是用于检测 KeyEvent 是否应触发给定按键绑定的原始类型。

Slint 中的按键绑定基于**逻辑键**——键在当前键盘布局上产生的字符——而不是键在键盘上的物理位置。
详情请参见 <Link type="KeyBindingOverview" label="按键绑定" />。

`keys` 值具有以下成员函数：

#### to-string() -> string

返回键组合的平台原生描述。

```slint
export component KeysToString inherits FocusScope {
    undo := KeyBinding {
        keys: @keys(Control + Z);
        activated => { debug("UNDO") }
    }

    Text {
        text: "Press \{undo.keys.to-string()} to undo!";
        // Results in "Press ⌘Z to undo!" on macOS
        // Results in "Press Ctrl+Z to undo!" on other platforms
    }
}

```

## 动画

<a id="easing"></a>

### easing

<SlintProperty propName="easing" typeName="easing" defaultValue='linear'>
`easing` 类型允许为动画定义缓动曲线。

要指定缓动曲线，请使用 `Easing` 命名空间中的值。例如可以使用 `Easing.ease-out` 或 `Easing.ease-in-quad`。该命名空间包含以下名称（可视化参考见 [`easings.net`](https://easings.net/)）：

    -   `linear`
    -   `ease-in-quad`
    -   `ease-out-quad`
    -   `ease-in-out-quad`
    -   `ease`
    -   `ease-in`
    -   `ease-out`
    -   `ease-in-out`
    -   `ease-in-quart`
    -   `ease-out-quart`
    -   `ease-in-out-quart`
    -   `ease-in-quint`
    -   `ease-out-quint`
    -   `ease-in-out-quint`
    -   `ease-in-expo`
    -   `ease-out-expo`
    -   `ease-in-out-expo`
    -   `ease-in-sine`
    -   `ease-out-sine`
    -   `ease-in-out-sine`
    -   `ease-in-back`
    -   `ease-out-back`
    -   `ease-in-out-back`
    -   `ease-in-circ`
    -   `ease-out-circ`
    -   `ease-in-out-circ`
    -   `ease-in-elastic`
    -   `ease-out-elastic`
    -   `ease-in-out-elastic`
    -   `ease-in-bounce`
    -   `ease-out-bounce`
    -   `ease-in-out-bounce`
    -   `cubic-bezier(a, b, c, d)`，与 CSS 中相同
    -   `spring(bounce)`，如 <Link type="Spring Animation" label="弹簧动画" /> 中所定义

此外，在 `easing` 类型的表达式中，这些名称可以直接使用。

```slint
struct AnimationData {
    curve: easing,
}

component Custom inherits Rectangle {
    property<AnimationData> animation: {
        // Using the Easing namespace.
        curve: Easing.ease-in-circ,
    };

	animate x {
    	// In easing expressions the names are available via global scope.
    	easing: ease-out-bounce;
	}
}
```

## 交互类型

### data-transfer

<SlintProperty propName="data" typeName="data-transfer" defaultValue='an empty data-transfer'>

`data-transfer` 值是拖放和剪贴板操作携带的负载。
它抽象了各平台支持的文件类型传输机制。
它可以同时携带纯文本、图像和本地文件路径列表。

该类型在 Slint 代码中是不透明的：
构造一个 `data-transfer` 值，并通过宿主语言实现的回调读取其内容。
端到端示例参见 <Link type="DragAndDrop" />。

### MouseCursor

<SlintProperty propName="mouse-cursor" typeName="MouseCursor" defaultValue='default'>
`MouseCursor` 类型用于 <Link type="TouchArea" label="TouchArea 元素"/>。

通过指定名称将其设置为内置形状之一：

```slint
TouchArea {
    mouse-cursor: ew-resize;
}

TouchArea {
    mouse-cursor: MouseCursor.ew-resize;
}
```
