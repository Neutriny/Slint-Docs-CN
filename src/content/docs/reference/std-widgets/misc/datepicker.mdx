使用日期选择器让用户选择日期。

```slint playground
import { DatePickerPopup, Button } from "std-widgets.slint";
export component Example inherits Window {
    width: 400px;
    height: 600px;

    date-picker-button := Button {
        text: @tr("Open Date Picker");

        clicked => {
            date-picker.show();
        }
    }

    date-picker := DatePickerPopup {
        x: (root.width - self.width) / 2;
        y: (root.height - self.height ) / 2;
        close-policy: PopupClosePolicy.no-auto-close;

        accepted(date) => {
            date-picker.close();
        }
        canceled => {
            date-picker.close();
        }
    }
}
```

## 属性

### title

<SlintProperty propName="title" typeName="string">
  显示在选择器顶部的文本。
</SlintProperty>

### date

<SlintProperty propName="date" typeName="struct" structName="Date">
设置初始显示的日期。
```slint "date: { year: 2024, month: 11 };"
DatePickerPopup {
    date: { year: 2024, month: 11 };
}
```
</SlintProperty>

## 回调

### canceled()

当点击取消按钮时调用。

```slint {2-4}
date-picker := DatePickerPopup {
    canceled() => {
        date-picker.close();
    }
}
```

### accepted(Date)

当点击确定按钮时调用。

```slint {2-5}
date-picker := DatePickerPopup {
    accepted(date) => {
        debug("Selected date: ", date);
        date-picker.close();
    }
}
```
