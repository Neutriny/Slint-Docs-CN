## 目的

本文档是 `.slint` 标记语言的规范性参考：
Slint 编译器接受什么，以及编译结果在运行时的行为。
它定义了 `.slint` 源文件是什么、其各部分如何组合，以及实现和用户必须遵守的约束。 \{#sls.meta.purpose}

[参考](../overview/)描述了构成 Slint API 表面的各个元素、属性和类型。
本规范描述的是其周围的语言本身。 \{#sls.meta.purpose-vs-reference}

## 约定

### 规范性措辞

关键字 **shall**、**should**、**may** 和 **must** 应按 ISO/IEC Directives Part 2 解释。
其他行文仅为说明性内容。 \{#sls.meta.conventions.normative}

### 代码示例

代码示例以 `slint` 围栏代码块格式化，除非另有明确说明，否则仅为说明性内容。 \{#sls.meta.conventions.examples}
