**FontWeight** 命名空间包含遵循 CSS 规范的各种字体粗细常量。

## 常量

以下常量在 **FontWeight** 命名空间中可用。它们都是无单位的 `float` 值。

| 名称          | 值    | 描述   |
| ------------- | ----- | ------ |
| `thin`        | `100` | 极细   |
| `extra-light` | `200` | 特细   |
| `light`       | `300` | 细     |
| `normal`      | `400` | 常规   |
| `medium`      | `500` | 中等   |
| `semi-bold`   | `600` | 半粗体 |
| `bold`        | `700` | 粗体   |
| `extra-bold`  | `800` | 特粗体 |
| `black`       | `900` | 黑体   |

## 示例

```slint
export component Example inherits Window {
    Text {
        text: "Hello World";
        font-weight: FontWeight.bold;
    }
}
```
