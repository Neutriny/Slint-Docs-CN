`Switch` 是物理开关的表示形式，允许用户打开或关闭某物。如果希望用户选择或取消选择值（例如在具有多个选项的列表中），请考虑改用 `CheckBox`。

## 属性

### checked
<SlintProperty typeName="bool" propName="checked" defaultValue="false" propertyVisibility="in-out">
开关是否已选中。

```slint "checked: true;"
Switch {
    text: self.checked ? "Checked" : "Not checked";
    checked: true;
}
````

</SlintProperty>

### enabled

<SlintProperty typeName="bool" propName="enabled" defaultValue="true">
  当为 false 时，开关无法被按下
</SlintProperty>

### has-focus

<SlintProperty typeName="bool" propName="has-focus" propertyVisibility="out">
  当开关具有键盘焦点时设置为 true
</SlintProperty>

### text

<SlintProperty typeName="string" propName="text" >
开关旁边显示的文本。

```slint 'text: "Switch with text";'
Switch {
    text: "Switch with text";
}
```

</SlintProperty>

## 回调

### toggled()

开关的值发生了变化

```slint {3-5}
Switch {
    text: "Switch";
    toggled() => {
        debug("Switch checked: ", self.checked);
    }
}
```
