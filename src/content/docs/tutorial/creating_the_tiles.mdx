  <TabItem label="Rust" icon="seti:rust">
  代码使用 `rand` 依赖来实现随机化。使用 `cargo` 命令将其添加到 `Cargo.toml` 文件中。

import mainTilesFromRust from '/src/content/code/main_tiles_from_rust.rs?raw';

<Code code={extractLines(mainTilesFromRust, 6, 26)} lang="rust" />

代码获取牌列表，将其复制并打乱，通过 Rust 代码访问 `memory_tiles` 属性。

对于每个顶层属性，
Slint 会生成一个 getter 和一个 setter 函数。在本例中为 `get_memory_tiles` 和 `set_memory_tiles`。
由于 `memory_tiles` 是一个 Slint 数组，表示为 <LangRefLink lang="rust-slint" relpath="trait.Model">`Rc<dyn slint::Model>`</LangRefLink>。

你无法更改 Slint 生成的模型，但可以从中提取牌并将它们
放入实现了 `Model` trait 的 <LangRefLink lang="rust-slint" relpath="struct.VecModel">`VecModel`</LangRefLink> 中。
`VecModel` 允许你进行修改，你可以用它来替换静态生成的模型。

  </TabItem>

代码获取牌列表，将其复制并打乱，通过 C++ 代码访问 `memory_tiles` 属性。

对于每个顶层属性，Slint 会生成一个 getter 和一个 setter 函数。在本例中为 `get_memory_tiles` 和 `set_memory_tiles`。
由于 `memory_tiles` 是一个 Slint 数组，它表示为 <LangRefLink lang="cpp" relpath="api/slint/model/">`std::shared_ptr<slint::Model>`</LangRefLink>。

你无法更改 Slint 生成的模型，但可以从中提取牌并将它们

`VectorModel` 允许你进行修改，你可以用它来替换静态生成的模型。
