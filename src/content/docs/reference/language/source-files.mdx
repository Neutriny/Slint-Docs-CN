## 文件扩展名

Slint 源文件使用文件扩展名 `.slint`。 \{#sls.source.file-extension.meta}

## 编码

`.slint` 源文件应编码为 UTF-8。 \{#sls.source.encoding.utf8}

UTF-8 字节顺序标记（`U+FEFF`）可以出现在文件开头，并会被忽略。 \{#sls.source.encoding.bom}

<a id="line-terminators"></a>

## 行终止符

编译器将字符 `U+000A`（LINE FEED）和两字符序列 `U+000D U+000A`（CARRIAGE RETURN, LINE FEED）识别为等价的行终止符。 \{#sls.source.line-terminators}

后面没有紧跟 `U+000A` 的 `U+000D`（CARRIAGE RETURN）不是行终止符。
源文件不应包含单独的回车符。 \{#sls.source.bare-cr}

## 空白

空白字符为 `U+0020`（SPACE）、`U+0009`（CHARACTER TABULATION），以及[行终止符](#line-terminators)中定义的行终止符。 \{#sls.source.whitespace.meta.chars}

空白用于分隔词法单元，除此之外无关紧要；一个或多个空白字符的任意序列都等价于单个空格。 \{#sls.source.whitespace.collapse}

## 注释

行注释以两个连续的斜线字符 `//` 开头，并延伸到下一个行终止符。 \{#sls.source.comment.line}

块注释由 `/*` 和 `*/` 界定。
块注释可以嵌套：块注释内的内层 `/*` 会增加嵌套深度，只有当匹配的 `*/` 将嵌套深度恢复到零时，注释才终止。 \{#sls.source.comment.block}

注释等价于空白；它们没有其他语义效果。 \{#sls.source.comment.whitespace-equivalent}

词法单元序列 `///` 和 `/**` 分别被识别为普通的行注释和块注释，不带有特殊含义。 \{#sls.source.comment.no-doc-comments}

```slint
// A line comment.

/* A block comment
   that spans multiple lines. */

/* Block comments /* may be nested */ like this. */
```
