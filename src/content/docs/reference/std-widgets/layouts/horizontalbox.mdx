description: HorizontalBox —— 带有适合主题的间距和内边距的 HorizontalLayout。

import Link from '@slint/common-files/src/components/Link.astro';

`HorizontalBox` 是一个 <Link type="HorizontalLayout" />，其默认 `padding` 和 `spacing` 来自 <Link type="StyleMetrics" />，
提供适合主题的值。当你需要完全控制间距和内边距时，请直接使用 `HorizontalLayout`。
