`TabWidget` 是一组标签页的容器。它只能有 `Tab` 元素作为子元素，并且一次只能有一个标签页
可见。

## 属性

### current-index

<SlintProperty typeName="int" propName="current-index" defaultValue="0">
当前可见标签页的索引。

```slint "current-index: 1;"
TabWidget {
    current-index: 1;

    Tab {
        title: "First";
    }
    Tab {
        title: "Second";
    }
}
```

</SlintProperty>

### orientation

<SlintProperty typeName="enum" enumName="Orientation" propName="orientation" defaultValue="horizontal">
标签栏的方向。
当设置为 `vertical` 时，标签栏放置在内容的左侧。
该属性必须是常量。
例如：
```slint
TabWidget {
    in property <Orientation> foo;
    // orientation: foo; // error
    orientation: Orientation.vertical; //valid
    Tab {
        title: "First";
    }
}
```
</SlintProperty>

## `Tab` 元素的属性

### title

<SlintProperty typeName="string" propName="title">
标签页上显示的文本。

```slint 'title: "First";'
TabWidget {
    Tab {
        title: "First";
    }
}
```

</SlintProperty>
