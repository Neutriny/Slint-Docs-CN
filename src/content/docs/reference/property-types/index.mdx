title: 总览
description: 属性、参数和返回值可以具有的类型。
---

_类型_ 是 [属性](../language/properties/)、函数或回调参数或返回值可以具有的东西：
[原始类型与数值类型](numeric-types/)、[字符串](strings/)、[颜色与画刷](colors-and-brushes/)、
[图像](images/)、[数组](arrays-and-models/)，以及你声明的[结构体和枚举](../language/structs-and-enums/)。

像 `Rectangle`、`TouchArea` 或 `Timer` 这样的元素类型不是属性类型：
它们实例化在元素树中，并在元素部分记录。
