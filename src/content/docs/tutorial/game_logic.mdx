这一步用你选择的编程语言实现游戏规则。

Slint 的总体理念是：在 Slint 中实现用户界面，在你喜欢的编程
语言中实现业务逻辑。

游戏规则规定最多只能有两张牌的帘幕处于打开状态。如果牌匹配，则游戏
认为它们已解开并保持打开。否则，游戏会短暂等待，让玩家记住
图标的位置，然后再次合上帘幕。
