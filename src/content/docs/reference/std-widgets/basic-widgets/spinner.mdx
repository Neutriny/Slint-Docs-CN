`Spinner` 向用户告知正在进行操作的进度状态，例如从网络加载数据。它提供与

<Link type="ProgressIndicator" /> 相同的属性，但形状不同。

## 属性

## indeterminate

<SlintProperty typeName="bool" propName="indeterminate" defaultValue="false">
  如果无法通过值确定操作的进度，则设置为 true。
</SlintProperty>

## progress

<SlintProperty typeName="float" propName="progress" defaultValue="0" >
完成百分比，为 0 到 1 之间的值。小于 0 或大于 1 的值将被限制。

```slint "progress: 0.5;"
Spinner {
    progress: 0.5;
}
```

</SlintProperty>
