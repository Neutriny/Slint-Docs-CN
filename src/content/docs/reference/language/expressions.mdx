<OnlyInSC>
表达式是颜色字面量、长度字面量、整数字面量、图像字面量、
布尔值、枚举值、结构体字面量、
算术、逻辑、一元或条件表达式、
属性引用或字段访问。 \{#sls.expr.forms}
</OnlyInSC>

表达式产生一个值。
字面量是最简单的形式：诸如 `42` 或 `3.14` 的数字，诸如 `100px` 或 `250ms` 的带单位数字，
布尔值 `true` 或 `false`，带 `\{ }` 插值的[字符串](../../property-types/strings/#string)，
或[颜色](#color-literals)。
其他形式包括[引用](#references)、[运算符或条件表达式](../operators/)、
[成员访问或索引](../operators/#member-access-and-indexing)、函数或回调调用、
数组或结构体字面量，以及诸如 `@image-url` 或 `@tr` 的宏。

<SC>
括号用于对嵌套表达式进行分组。 \{#sls.expr.grouping}

<a id="color-literals"></a>

## 颜色字面量

颜色字面量由 `#` 后跟 3、4、6 或 8 个十六进制数字组成：
`#rgb`、`#rgba`、`#rrggbb` 或 `#rrggbbaa`。
这些数字不区分大小写。
任何其他位数的数字都是一个错误。 \{#sls.expr.color.forms}

这些数字按顺序指定红、绿、蓝和 alpha 通道。
当省略 alpha 通道时，颜色完全不透明。 \{#sls.expr.color.channels}

在 3 位和 4 位形式中，每个数字通过重复来指定一个通道：
`#18f` 与 `#1188ff` 是同一种颜色。 \{#sls.expr.color.short-forms}

颜色字面量求值为 `color` 类型的值。 \{#sls.expr.color.type}

## 长度字面量

长度字面量由数字直接后跟一个单位组成，例如 `120px`。 \{#sls.expr.length.form}

```slint
export component Example inherits Window {
    Rectangle {
        width: 120px;
        height: 80px;
        background: #2a6e3f;
    }
}
```

</SC>

<OnlyInSC>
数字应为整数：`10.5px` 是一个错误。 \{#sls.expr.length.integral}

`px` 是唯一的单位。
带其他单位的数字字面量是一个错误。 \{#sls.expr.length.px-only}

</OnlyInSC>

数字可以是小数，例如 `10.5px`。
长度单位包括 `px`、`phx`、`cm`、`mm`、`in`、`pt` 和 `rem`。

<SC>
长度字面量求值为 `length` 类型的值。 \{#sls.expr.length.type}

## 整数字面量

整数字面量是不带单位书写的整数，例如 `42`。 \{#sls.expr.int.form}

整数字面量求值为 `int` 类型的值。 \{#sls.expr.int.type}

<OnlyInSC>
带小数部分但不带单位的数字是一个错误。 \{#sls.expr.int.fractional}
</OnlyInSC>

<SC>
## 图像字面量

图像字面量由 `@image-url(`、双引号中的字符串字面量，
以及 `)` 组成。 \{#sls.expr.image.form}

```slint
export component Example inherits Window {
    in property <image> logo: @image-url("images/logo.png");
}
```

该字符串是图像文件的路径：绝对路径，或相对于包含该字面量的 `.slint` 文件所在目录解析的路径。 \{#sls.expr.image.path}

空字符串求值为无图像。 \{#sls.expr.image.empty}

图像字面量求值为 `image` 类型的值。 \{#sls.expr.image.type}

</SC>

<NotInSC>
  该路径也可以指向编译器包含路径上的文件，并且图像还可以从 `data:` URI 或 URL
  加载；[图像类型](../../property-types/images/)描述了这些形式以及 `nine-slice`
  参数。
</NotInSC>

<OnlyInSC>
该文件应存在，并包含编译器可解码格式的栅格图像，例如 PNG 或 JPEG。
SVG 图像是一个错误：在渲染之前它没有可供解码的像素。 \{#sls.expr.image.raster-only}

该字符串应是一个路径：`data:` URI 或 URL 是一个错误。 \{#sls.expr.image.path-only}

完整 Slint 中的 `nine-slice` 参数是一个错误。 \{#sls.expr.image.no-nine-slice}

</OnlyInSC>

<a id="references"></a>

## 引用

```slint
export component Example inherits Window {
    in property <color> tint;
    Rectangle {
        background: root.tint;
        width: self.height;
    }
}
```

属性引用指向某个属性。
它是一个属性名，可选地前面带有一个元素引用和一个 `.`。 \{#sls.expr.ref.form}

元素引用对于外层元素是 `self`，对于其父元素是 `parent`，
对于组件的根元素是 `root`，或者是元素的 `id`。 \{#sls.expr.ref.element}

预定义名字 `true` 和 `false` 是对 `bool` 类型两个值的引用。 \{#sls.expr.bool}

不带元素引用的名字遵循[查找规则](../name-resolution/#lookup-rules)。 \{#sls.expr.ref.lookup}

该名字应指向被引用元素的一个属性。 \{#sls.expr.ref.target}

读取时，属性引用求值为被引用属性的值，
并具有该属性的类型。 \{#sls.expr.ref.value}

</SC>

不带元素引用时，名字也可以解析为局部变量、回调或函数。

引用也可以命名[枚举](../structs-and-enums/#enums)值或[全局对象](../globals/)的属性。
