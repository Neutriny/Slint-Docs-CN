本教程通过实现一个记忆游戏，以有趣的方式向你介绍 Slint 框架。它将用于图形的 Slint 语言与用 C++、Rust、NodeJS 或 Python 实现的游戏规则结合在一起。

游戏由 16 张矩形牌组成的网格构成。点击一张牌会露出下面的图标。
总共有 8 种不同的图标，因此每张牌在网格中的某处都有一张具有
相同图标的配对牌。目标是找出所有配对的图标。玩家可以同时翻开两张牌。如果它们
不相同，游戏会再次遮住这些图标。
如果玩家翻开的两张牌图标相同，它们就会保持可见——即已解开。
