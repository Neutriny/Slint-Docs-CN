<SC>
元素有一组具名*属性*，由其类型决定：
元素的类型提供属性——包括它
[继承](../file-structure/#sls.file.component.inherits)自基类的那些——
而元素体中的[属性声明](#property-declaration)会添加更多。 \{#sls.prop.def}

属性持有该属性类型的值；
读取该属性会得到其当前值。 \{#sls.prop.def.value}

<a id="property-declaration"></a>

## 属性声明

_属性声明_ 会向其所在元素体内添加一个属性。
它由关键字 `property`、尖括号中的类型和一个名字组成，
可选地在前面带有一个可见性修饰符，
可选地在后面跟 `:` 以及一个[绑定](../bindings/)到该属性的表达式，
并以 `;` 结尾。 \{#sls.prop.decl.form}

```slint
export component Example inherits Window {
    in property <color> tint;
    in-out property <length> gap: 10px;
}
```

修饰符声明属性的*可见性*：
即哪一侧可以读取和设置属性的值。 \{#sls.prop.decl.visibility}

`in` 属性是组件的输入。 \{#sls.prop.decl.in}

在应用直接实例化的组件的根元素上，应用通过生成的 API
设置其值。 \{#sls.prop.decl.in.root}

在任何其他元素上，外层组件通过绑定设置其值。 \{#sls.prop.decl.in.child}

`out` 属性是组件的输出：
组件确定其值，应用读取它。 \{#sls.prop.decl.out}

`in-out` 属性兼具两者：应用设置并读取其值。 \{#sls.prop.decl.in-out}

`private` 属性是组件内部的：
应用既不能设置也不能读取它。
私有是默认值：不带修饰符的声明声明一个私有属性。 \{#sls.prop.decl.private}

<OnlyInSC>
属性应仅在根元素上声明。 \{#sls.prop.decl.root-only}
</OnlyInSC>
</SC>

属性可以在任何元素上声明。

<SC>
<OnlyInSC>
所声明的类型可以是任何有效的属性类型。 \{#sls.prop.decl.types}
</OnlyInSC>
</SC>

可以声明任何[属性类型](../../property-types/)。

<SC>
没有绑定时，属性具有其类型的默认值。 \{#sls.prop.decl.default}
</SC>

[变更回调](../callbacks/#change-callbacks)对属性值的变化作出反应，
而带[双向绑定](../two-way-bindings/)的声明会将新属性链接到现有属性。

声明前可以带有 [`@deprecated` 注解](../deprecation/)，
它会将该属性标记为已废弃，并指引用户使用其替代者。
