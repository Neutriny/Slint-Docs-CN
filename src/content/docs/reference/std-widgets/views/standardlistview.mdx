类似 ListView，但带有默认委托和一个 `model` 属性。

## 属性

与 <Link type="ListView" /> 相同，另外还有：

### current-item
<SlintProperty typeName="int" propName="current-item" defaultValue="-1" propertyVisibility="in-out">
当前活动项的索引。-1 表示未选中任何项，这是默认值
</SlintProperty>

### model
<SlintProperty typeName="struct" structName="StandardListViewItem" propName="model" defaultValue="[]">
模型。

```slint 'model: [{ text: "Blue" }, { text: "Red" }, { text: "Green" }];'
StandardListView {
    model: [{ text: "Blue" }, { text: "Red" }, { text: "Green" }];
}
````

</SlintProperty>

## 函数

### set-current-item(int)

通过指定的索引设置当前项，并将其滚动到可见区域。

## 回调

### current-item-changed(int)

当当前项因用户修改而发生变化时发出

```slint {3-5}
StandardListView {
    model: [{ text: "Blue" }, { text: "Red" }, { text: "Green" }];
    current-item-changed(index) => {
        debug("Current item: ", index);
    }
}
```

### item-pointer-event(int, PointerEvent, Point)

在任何鼠标指针事件上发出，类似于 `TouchArea`。参数为与该事件关联的项索引、`PointerEvent` 本身以及 listview 内的鼠标位置。
