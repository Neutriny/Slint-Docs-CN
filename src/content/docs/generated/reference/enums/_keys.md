The `Key` namespace contains the well-known logical key codes. The upstream
Slint documentation generator emits this table; this port does not ship the
generator, so the table below is a hand-maintained stub.

| Key                  | Description                 |
| -------------------- | --------------------------- |
| `Key.Backspace`      | Backspace                   |
| `Key.Tab`            | Tab                         |
| `Key.Return`         | Enter / Return              |
| `Key.Escape`         | Escape                      |
| `Key.Space`          | Space                       |
| `Key.Delete`         | Delete                      |
| `Key.UpArrow`        | Up arrow                    |
| `Key.DownArrow`      | Down arrow                  |
| `Key.LeftArrow`      | Left arrow                  |
| `Key.RightArrow`     | Right arrow                 |
| `Key.Home`           | Home                        |
| `Key.End`            | End                         |
| `Key.PageUp`         | Page up                     |
| `Key.PageDown`       | Page down                   |
| `Key.Shift`          | Shift modifier              |
| `Key.Control`        | Control modifier            |
| `Key.Alt`            | Alt modifier                |
| `Key.Meta`           | Meta / Command modifier     |
| `Key.F1` … `Key.F12` | Function keys               |
| `Key.a` … `Key.z`    | Alphabetic keys (lowercase) |
| `Key.0` … `Key.9`    | Digit keys                  |
