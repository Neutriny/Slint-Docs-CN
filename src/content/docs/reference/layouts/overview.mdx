## 属性

这些属性对所有可见项有效，并且可以在布局中使用时指定约束：

### col, row

<SlintProperty propName="col, row" typeName="int" defaultValue="0">
  参见 <Link type="GridLayout" />。
</SlintProperty>

### colspan, rowspan

<SlintProperty propName="colspan, rowspan" typeName="int">
  参见 <Link type="GridLayout" />。
</SlintProperty>

### cross-axis-self-alignment

<SlintProperty
  propName="cross-axis-self-alignment"
  typeName="enum"
  enumName="CrossAxisAlignment"
  defaultValue="auto"
>
  覆盖容器对此元素的 `cross-axis-alignment`。对 <Link type="HorizontalLayout" />
  、 <Link type="VerticalLayout" /> 或 <Link type="FlexboxLayout" />{' '}
  的子元素有效。
</SlintProperty>

### horizontal-stretch, vertical-stretch

<SlintProperty
  propName="horizontal-stretch, vertical-stretch"
  typeName="float"
  propertyVisibility="in-out"
>
  指定这些元素在布局中拉伸的相对空间量。 当为 0
  时，这意味着元素不会被拉伸，除非所有元素 都为 0。内置部件的值为 0 或 1。
</SlintProperty>

### layout-order

<SlintProperty propName="layout-order" typeName="int" defaultValue="0">
  控制元素的视觉顺序：它们按值升序 布局，具有相同值的元素保持其声明顺序。 对{' '}
  <Link type="HorizontalLayout" />、 <Link type="VerticalLayout" /> 或{' '}
  <Link type="FlexboxLayout" /> 的子元素有效。只有
  视觉顺序会改变：键盘焦点仍按声明顺序移动。
</SlintProperty>

### max-width, max-height

<SlintProperty propName="`max-width, `max-height" typeName="length">
  元素的最大尺寸。
</SlintProperty>

### min-width, min-height

<SlintProperty propName="`min-width, `min-height" typeName="length">
  元素的最小尺寸。
</SlintProperty>

### preferred-width, preferred-height

<SlintProperty propName="`preferred-width, `preferred-height" typeName="length">
  元素的首选尺寸。
</SlintProperty>
