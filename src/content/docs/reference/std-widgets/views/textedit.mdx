## 函数

### focus()

调用此函数以聚焦 TextEdit 并使其接收后续键盘事件。

### clear-focus()

调用此函数以从此 `TextEdit` 移除键盘焦点（如果它当前具有焦点）。另请参见 <Link type="FocusHandling" label="焦点处理" />。

### set-selection-offsets(anchor: int, focus: int)

选择两个 UTF-8 偏移之间的文本：`anchor` 是保持不动的选择端，`focus` 是光标移动到的端，因此 `focus` 可以先于 `anchor` 以反向选择。为两者传递相同的值可将文本光标放置在该偏移处而不选择任何内容。

### select-all()

选择所有文本。

### clear-selection()

清除选择。无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

### copy()

将选中的文本复制到剪贴板。

### cut()

将选中的文本复制到剪贴板并从可编辑区域中移除。无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

### paste()

将剪贴板的文本内容粘贴到光标位置。无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

### undo()

撤销上次文本操作。无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

### redo()

重做上次撤销的文本操作。无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

## 回调

### edited(string)

当文本因用户修改而发生变化时发出

```slint {2-4}
TextEdit {
    edited(text) => {
        debug("Edited: ", text);
    }
}
```

### key-pressed(KeyEvent) -> EventResult

当按键被按下时调用，参数是一个 <Link type="KeyEvent" /> 结构体。使用此回调在 `TextEdit`
处理键之前处理按键。返回 `accept` 表示你已处理该事件，或返回
`reject` 让 `TextEdit` 处理它。

### key-released(KeyEvent) -> EventResult

当按键被释放时调用，参数是一个 <Link type="KeyEvent" /> 结构体。使用此回调在 `TextEdit`
处理键之前处理按键。返回 `accept` 表示你已处理该事件，或返回
`reject` 让 `TextEdit` 处理它。
