一个按钮，点击后会打开弹出窗口以选择值。

## 属性

### current-index

<SlintProperty propName="current-index" typeName="int" defaultValue="0" propertyVisibility="in-out">
所选值的索引。
```slint "current-index: 1;"
ComboBox {
    model: ["first", "second", "third"];
    current-index: 1;
}
```
</SlintProperty>

### current-value

<SlintProperty propName="current-value" typeName="string" defaultValue='""' propertyVisibility="in-out">
当前选中的文本。

:::note
向 `current-value` 写入 —— 来自宿主代码（Rust、C++、JavaScript、Python）、在实例化时以声明方式
（如上面的示例），或从 `.slint` 代码中以命令方式 —— 会在 `model` 中查找
写入的值，并将 `current-index` 移动到第一个匹配的行。如果在 `model` 中
找不到该值，则清除选择（`current-index` 变为 `-1`，
`current-value` 变为 `""`），这等同于将 `current-index` 设置为超出范围。
当行的位置已知时，建议直接写入 `current-index`。

此查找仅在写入实际更改 `current-value` 时运行。写入它已持有的值 ——
包括当模型包含重复条目且当前选中靠后的一个时 —— 是空操作，
不会移动选择。
:::

</SlintProperty>

### enabled

<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
  默认为 true。当为 false 时，无法与组合框交互
</SlintProperty>

### has-focus

<SlintProperty propName="has-focus" typeName="bool" propertyVisibility="out">
  当组合框具有键盘焦点时设置为 true。
</SlintProperty>

### model

<SlintProperty propName="model" typeName="[string]" defaultValue="[]">
可能值的列表
```slint 'model: ["first", "second", "third"];'
ComboBox {
    model: ["first", "second", "third"];
}
```

:::note[注意]
设置此属性时，`ComboBox` 会尝试保留 `current-index`。
如果 `current-index` 大于新模型的长度，则将其设置为模型中的最后一项。
:::

</SlintProperty>

## 回调

### selected(string)

用户从组合框中选择了值。参数为当前选中的值。

```slint {3-5}
ComboBox {
    model: ["first", "second", "third"];
    selected(value) => {
        debug("Selected value: ", value);
    }
}
```
