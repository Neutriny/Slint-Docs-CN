使用 `CheckBox` 让用户选择或取消选择值，例如在具有多个选项的列表中。如果该操作更像是打开或关闭某物，请考虑改用 `Switch` 元素。

## 属性

### checked

<SlintProperty propName="checked" typeName="bool" defaultValue="false" propertyVisibility="in-out">
复选框是否已选中。
```slint "checked: true;"
CheckBox {
    text: self.checked ? "Checked" : "Not checked";
    checked: true;
}
```
</SlintProperty>

### enabled

<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
  默认为 true。当为 false 时，复选框无法被按下。
</SlintProperty>

### font-size

<SlintProperty propName="font-size" typeName="length">
  标签文本的字体大小。
</SlintProperty>

### font-weight

<SlintProperty propName="font-weight" typeName="int">
  标签文本的字体粗细。
</SlintProperty>

### has-focus

<SlintProperty propName="has-focus" typeName="bool" propertyVisibility="out">
  当复选框具有键盘焦点时设置为 true。
</SlintProperty>

### text

<SlintProperty propName="text" typeName="string">
复选框旁边显示的文本。
```slint 'text: "CheckBox with text";'
CheckBox {
    text: "CheckBox with text";
}
```
</SlintProperty>

## 回调

### toggled()

复选框的值发生了变化

```slint {3-5}
CheckBox {
    text: "CheckBox";
    toggled() => {
        debug("CheckBox checked: ", self.checked);
    }
}
```
