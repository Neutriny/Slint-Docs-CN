Slint 元素有许多通用属性、回调和行为。
本页介绍这些属性及其用法。

## 通用视觉属性

这些属性对所有可视项都有效。例如 `Rectangle`、`Text` 和 `layouts`。非可视项（如 `Timer`）没有这些属性。

### x, y

<SlintProperty propName="x, y" typeName="length">
  元素相对于其父元素的位置。
</SlintProperty>

### z

<SlintProperty propName="z" typeName="float">
  元素在其兄弟元素之间的堆叠顺序。`z` 值更高的兄弟元素绘制在上层，
  并且最先接收输入。默认值为 0，共享相同 `z` 的兄弟元素保持其声明顺序。
</SlintProperty>

### width, height

<SlintProperty propName="width, height" typeName="length">
  元素的宽度和高度。设置后会覆盖默认尺寸。
</SlintProperty>

### 变换

变换允许围绕指定的原点旋转和缩放项。默认原点是元素的中心。

软件渲染器不支持变换。

```slint {5-7}
Image {
    x: 0;
    y: 0;
    source: @image-url("images/slint-logo.svg");
    transform-rotation: 45deg;
    transform-origin: {x: 0, y: 0};
}
```

#### transform-rotation

<SlintProperty
  propName="transform-rotation"
  typeName="angle"
  defaultValue="0deg"
/>

#### transform-origin

<SlintProperty propName="transform-origin" typeName="struct" structName="Point" defaultValue='{x: self.width / 2, y: self.height / 2}'>
旋转和缩放所围绕的原点。

默认为元素的中心。

</SlintProperty>

#### transform-scale

<SlintProperty propName="transform-scale" typeName="float" defaultValue='100%'>
应用于元素及其所有子元素的缩放因子。

这不会影响元素的几何尺寸（width、height），但会影响渲染。
缩放围绕 `transform-origin` 点进行。

也可以使用 `transform-scale-x` 和 `transform-scale-y` 属性来指定 x 轴和 y 轴的缩放因子。

</SlintProperty>

#### transform-scale-x

<SlintProperty
  propName="transform-scale-x"
  typeName="float"
  defaultValue="self.scale"
/>
#### transform-scale-y
<SlintProperty
  propName="transform-scale-y"
  typeName="float"
  defaultValue="self.scale"
/>

<SlintProperty propName="opacity" typeName="float" defaultValue="1">

元素及其子元素。

然后整个图层以该不透明度进行渲染。

:::note

:::

### visible
<SlintProperty propName="visible" typeName="bool" defaultValue="true">
当设置为 `false` 时，元素及其所有子元素都不会被绘制，也不会响应鼠标输入。元素
仍然占用任何布局容器中的布局空间。

</SlintProperty>

### absolute-position
<SlintProperty propName="absolute-position" typeName="struct" structName="Point" propertyVisibility="out">

在包含许多嵌套组件的 UI 中，了解它们相对于主窗口或屏幕的 (x,y) 位置很有用。
这个便捷属性提供了对该值的简单只读访问。它表示一个点，指定其在所属 <Link type="Window"/> 或 <Link type="PopupWindow"/> 内的绝对位置。
它定义了相对于所属 Window 或 PopupWindow 的坐标 (x,y)，但参考系未指定
（可能是屏幕、窗口或弹出窗口坐标）。
</SlintProperty>



## 杂项

### cache-rendering-hint
<SlintProperty typeName="bool" propName="cache-rendering-hint" defaultValue="false" >
当设置为 `true` 时，这会向渲染器提供提示，将元素及所有子元素的内容
缓存到一个中间缓存图层中。对于很少变化的复杂子树，
这可能会加快渲染速度，代价是增加内存消耗。

:::note
并非所有渲染后端都支持此属性。
:::
</SlintProperty>



### dialog-button-role
<SlintProperty typeName="enum" enumName="DialogButtonRole" defaultValue="none">
指定这是 `Dialog` 中的按钮。
</SlintProperty>

## 通用回调

### init()

每个元素都隐式声明一个 `init` 回调。你可以为元素分配一个代码块，在元素
实例化后且所有属性都以其最终绑定的值初始化后调用。调用
顺序是从内到外。下面的示例依次打印 "first"、"second"，然后 "third"：

```slint
component MyButton inherits Rectangle {
    in-out property <string> text: "Initial";
    init => {
        // If `text` is queried here, it will have the value "Hello".
        debug("first");
    }
}

component MyCheckBox inherits Rectangle {
    init => { debug("second"); }
}

export component MyWindow inherits Window {
    MyButton {
        text: "Hello";
        init => { debug("third"); }
    }
    MyCheckBox {
    }
}
````

不要使用此回调来初始化属性，因为这会违反声明式原则。

尽管所有组件上都存在 `init` 回调，但无法从应用程序代码中设置它，
例如，生成的代码中不存在 `on_init` 函数。
这是因为该回调在组件创建时就被调用，
早于你可以调用 `on_init` 来实际设置它。

虽然 `init` 回调可以调用其他回调（例如在 `global` 段中定义的回调），并且
你 _可以_ 在后端绑定这些回调，但这对于静态创建的组件（包括
窗口本身）不起作用，因为你需要一个实例来设置全局绑定。但可以
将其用于动态创建的组件（例如 `if` 后面的组件）：

```slint
export global SystemService  {
    // This callback can be implemented in native code using the Slint API
    callback ensure_service_running();
}

component MySystemButton inherits Rectangle {
    init => {
        SystemService.ensure_service_running();
    }
    // ...
}

export component AppWindow inherits Window {
    in property <bool> show-button: false;

    // MySystemButton isn't initialized at first, only when show-button is set to true.
    // At that point, its init callback will call ensure_service_running()
    if show-button : MySystemButton {}
}
```

## 无障碍属性

使用以下 `accessible-` 属性，让你的项与屏幕阅读器、盲文终端以及其他
无障碍软件良好交互，使你的应用程序具备无障碍能力。
必须先设置 `accessible-role`，才能设置任何其他无障碍属性或回调。

### accessible-role

<SlintProperty typeName="enum" enumName="AccessibleRole">
  元素的角色。要使用任何其他无障碍属性，此属性是必需的。
  它应设置为常量值。（默认值：大多数元素为 `none`，但 Text 元素为 `text`）
</SlintProperty>

### accessible-checkable

<SlintProperty
  typeName="bool"
  propName="accessible-checkable"
  defaultValue="false"
>
  元素是否可以被勾选。
</SlintProperty>

### accessible-checked

<SlintProperty
  typeName="bool"
  propName="accessible-checked"
  defaultValue="false"
>
  元素是否被勾选。这映射到复选框、单选按钮和其他部件的 "checked" 状态。
</SlintProperty>

### accessible-description

<SlintProperty
  typeName="string"
  propName="accessible-description"
  defaultValue='""'
>
  当前元素的描述。
</SlintProperty>

### accessible-enabled

<SlintProperty
  typeName="bool"
  propName="accessible-enabled"
  defaultValue="true"
>
  元素是否启用。这映射到大多数部件的 "enabled" 状态。（默认值：`true`）
</SlintProperty>

### accessible-expandable

<SlintProperty
  typeName="bool"
  propName="accessible-expandable"
  defaultValue="false"
>
  元素是否可以展开。例如，`ComboBox` 部件 应将其设置为
  true，因为其选择可以通过可展开的 弹出窗口进行更改。
</SlintProperty>

### accessible-expanded

<SlintProperty
  typeName="bool"
  propName="accessible-expanded"
  defaultValue="false"
>
  元素是否已展开。适用于组合框、菜单项、 树视图项和其他部件。
</SlintProperty>

### accessible-id

<SlintProperty typeName="string" propName="accessible-id" defaultValue='""'>
元素的唯一标识符，用于在自动化和测试中识别部件。
此属性可以设置为任意字符串值，在编写自动化测试或
使用无障碍工具唯一识别应用程序中的特定部件时特别有用。

如果需要识别重复的元素，请确保为每个实例分配不同的值，如下所示。

```slint
for i in 5: Rectangle {
    accessible-role: button;
    accessible-id: "btn-" + i;
    accessible-label: "Button " + i;
}
```

</SlintProperty>

### accessible-label

<SlintProperty typeName="string" propName="accessible-label" defaultValue='""'>
  交互元素的标签。（默认值：大多数元素为空， 或 Text 元素的 `text` 属性值）
</SlintProperty>

### accessible-orientation

<SlintProperty typeName="enum" enumName="Orientation">
  元素在适用时的方向，例如 `Slider` 或 `ScrollBar`。辅助技术可以用它来告知用户
  部件是水平还是垂直布局。
</SlintProperty>

### accessible-live-region

<SlintProperty
  typeName="enum"
  propName="accessible-live-region"
  enumName="AccessibleLiveness"
>
  将元素标记为活动区域，当其文本内容变化时应由辅助技术播报。 非紧急更新使用
  `polite`，应打断用户的更新使用 `assertive`。 默认的 `off` 禁用活动播报。
</SlintProperty>

### accessible-value-maximum

<SlintProperty
  typeName="float"
  propName="accessible-value-maximum"
  defaultValue="0"
>
  项的最大值。例如微调框会使用它。
</SlintProperty>

### accessible-value-minimum

<SlintProperty
  typeName="float"
  propName="accessible-value-minimum"
  defaultValue="0"
>
  项的最小值。
</SlintProperty>

### accessible-value-step

<SlintProperty
  typeName="float"
  propName="accessible-value-step"
  defaultValue="0"
>
  当前值可以改变的最小增量或减量。 这对应于滑块上手柄可以拖动的步长。
</SlintProperty>

### accessible-value

<SlintProperty typeName="string" propName="accessible-value" defaultValue='""'>
  项的当前值。
</SlintProperty>

### accessible-placeholder-text

<SlintProperty
  typeName="string"
  propName="accessible-placeholder-text"
  defaultValue='""'
>
  项的值为空时使用的占位文本。适用于文本 元素。
</SlintProperty>

### accessible-read-only

<SlintProperty
  typeName="bool"
  propName="accessible-read-only"
  defaultValue="false"
>
  元素的内容是否可编辑。这映射到行编辑和文本编辑部件的 "read-only" 状态。
</SlintProperty>

### accessible-item-selectable

<SlintProperty typeName="bool" propName="accessible-item-selectable">
  元素是否可以被选中。
</SlintProperty>

### accessible-item-selected

<SlintProperty typeName="bool" propName="accessible-item-selected">
  元素是否被选中。这映射到列表视图项的 "is-selected" 状态。
</SlintProperty>

### accessible-item-index

<SlintProperty typeName="int" propName="accessible-item-index">
  此元素在一组相似元素中的索引（从 0 开始）。 适用于列表项、单选按钮和其他元素。
</SlintProperty>

### accessible-item-count

<SlintProperty typeName="int" propName="accessible-item-count">
  一组元素的总数。适用于一组元素的父容器， 例如列表视图、单选按钮组或其他分组
  元素。
</SlintProperty>

## 无障碍回调

你还可以使用以下由无障碍框架调用的回调：

### accessible-action-default()

当请求此部件的默认操作时调用，例如按钮的按下操作。

### accessible-action-set-value(string)

当用户想要更改无障碍值时调用。

### accessible-action-increment()

当用户请求增加值时调用。

### accessible-action-decrement()

当用户请求减少值时调用。

### accessible-action-expand()

当用户请求展开部件时调用，例如展开组合框的可用选项列表。

### accessible-action-set-selection-offsets(anchor: int, focus: int)

当用户想要更改选中的文本时调用。参数是元素文本中的 UTF-8 偏移量：`anchor` 是保持不动的端点，`focus` 是移动的端点，因此当选择是反向进行时 `focus` 可能在 `anchor` 之前，而当只有光标移动时两者相等。
