有了骨架代码之后，这一步来看游戏的第一个元素——记忆牌。它是
一个可视化构建块，由底层填充的矩形背景和图标图像组成。后续步骤会添加一个作为帘幕的覆盖矩形。

你将背景矩形声明为 64 个逻辑像素宽和高，
并填充一种柔和的蓝色调。

Slint 中的长度带有单位，这里使用 `px` 后缀。
这让代码更易读，编译器也能检测出你何时意外
混合了带有不同单位的数值。

将以下代码复制到 `ui/app-window.slint` 文件中，替换当前内容：

import memoryTile from '/src/content/code/memory_tile.slint?raw';

<Code code={extractLines(memoryTile, 5, 19)} lang="slint" />

这会导出 <span class="hljs-title">MainWindow</span> 组件，以便游戏逻辑代码稍后可以访问它。

在 <span class="hljs-built_in">Rectangle</span> 内部放置一个 <span class="hljs-built_in">Image</span> 元素，
它使用 <span class="hljs-built_in">@image-url()</span> 宏加载一个图标。路径相对于 `ui/app-window.slint` 的位置。

你需要先安装这个图标以及稍后使用的其他图标。你可以下载一个预先准备好的
[Zip 归档](https://slint.dev/blog/memory-game-tutorial/icons.zip) 到 `ui` 文件夹，

如果你在 Linux 或 macOS 上，使用以下命令下载并解压它：

<Tabs syncKey="dev-platform">
<TabItem label="Windows" icon="seti:windows">

如果你在 Windows 上，使用以下命令：

```powershell title="PowerShell"
cd ui
powershell curl -Uri https://slint.dev/blog/memory-game-tutorial/icons.zip -Outfile icons.zip
powershell Expand-Archive -Path icons.zip -DestinationPath .
cd ..
```

这会解压出一个包含若干图标的 `icons` 目录。

</TabItem>
<TabItem label="macOS" icon="apple">
```sh title="Terminal"
cd ui
curl -O https://slint.dev/blog/memory-game-tutorial/icons.zip
unzip icons.zip
cd ..
```
这会解压出一个包含若干图标的 `icons` 目录。
</TabItem>
<TabItem label="Linux" icon="linux">

```sh title="Bash"
cd ui
curl -O https://slint.dev/blog/memory-game-tutorial/icons.zip
unzip icons.zip
cd ..
```

这会解压出一个包含若干图标的 `icons` 目录。

</TabItem>
</Tabs>
