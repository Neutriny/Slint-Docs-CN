<SC>
## 属性

每个元素都有四个几何属性 `x`、`y`、`width` 和 `height`，其类型为 `length`。 \{#sls.geom.properties}

`x` 和 `y` 是从元素父元素左上角到元素左上角的偏移量。
`width` 和 `height` 是元素的大小，从该角向右和向下延伸。 \{#sls.geom.relative}

根元素的 `x` 和 `y` 属性没有意义，不得使用。 \{#sls.geom.window.root}

<OnlyInSC>
根元素的 `width` 和 `height` 是窗口的大小，由应用在创建组件时
赋予组件。 \{#sls.geom.window.size}

表达式可以读取它们，因此元素可以相对于窗口来确定自身大小。
绑定根元素的任何几何属性都是一个错误：大小应由应用给出，
而不是由文件设置。 \{#sls.geom.window}

</OnlyInSC>
</SC>

绑定根元素的 `x` 或 `y` 已废弃。
窗口大小可以通过 `width` 和 `height` 设置。

<SC>
## 默认值

当 `x` 没有绑定时，它默认为 `(parent.width - self.width) / 2`，
`y` 默认为 `(parent.height - self.height) / 2`：
即沿该轴将元素在其父元素中居中的值。 \{#sls.geom.default-position}

当 `width` 或 `height` 没有绑定时，默认值取决于元素类型：
`Rectangle` 的宽度或高度与其父元素相同。 \{#sls.geom.default-size}

</SC>

布局内的元素由布局定位和确定大小，而不是使用这些默认值。

<SC>
在此示例中，两个矩形都覆盖整个窗口： \{#sls.geom.example.intro}

```slint
export component Example inherits Window {
    Rectangle {
        background: #2a6e3f;
        Rectangle {
        }
    }
}
```

</SC>

求值为[百分比](../../property-types/numeric-types/#percent)的 `width` 或 `height` 绑定
相对于父元素的同名属性：
`width: 50%;` 是 `width: parent.width * 50%;` 的简写。
