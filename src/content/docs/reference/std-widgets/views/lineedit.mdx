用于输入单行文本的控件。有关能够处理多行文本的控件，请参见 <Link type="TextEdit" />。

## 属性

### enabled
<SlintProperty propName="enabled" typeName="bool" defaultValue="true">
当为 false 时，无法输入任何内容。
</SlintProperty>

### font-size
<SlintProperty propName="font-size" typeName="length">
输入文本的字体大小
</SlintProperty>

### font-family
<SlintProperty propName="font-family" typeName="string">
输入文本的字体系列
</SlintProperty>

### font-italic
<SlintProperty propName="font-italic" typeName="bool" defaultValue="false">
输入文本的字体斜体状态
</SlintProperty>

### has-focus
<SlintProperty propName="has-focus" typeName="bool" propertyVisibility="out">
当单行编辑器当前具有焦点时设置为 true
</SlintProperty>

### horizontal-alignment
<SlintProperty propName="horizontal-alignment" typeName="enum" enumName='TextHorizontalAlignment' defaultValue="left">
文本的水平对齐方式。
</SlintProperty>

### input-method-hints
<SlintProperty propName="input-method-hints" typeName="struct" structName="InputMethodHints">
平台输入法（例如软键盘）的提示，例如用于配置自动大写。
输入法可能会考虑这些提示，也可能忽略它们。
```slint "input-method-hints: { capitalization: CapitalizationMode.words };"
LineEdit {
    input-method-hints: { capitalization: CapitalizationMode.words };
}
````

</SlintProperty>

### input-type

<SlintProperty propName="input-type" typeName="enum" enumName="InputType" defaultValue="text">
允许特殊输入视图属性（如密码字段）的方式。
```slint "input-type: password;"
LineEdit {
    input-type: password;
}
```
</SlintProperty>

### placeholder-text

<SlintProperty propName="placeholder-text" typeName="string">
  编辑字段中没有文本时显示的占位文本
</SlintProperty>

### read-only

<SlintProperty propName="read-only" typeName="bool" defaultValue="false">
  设置为 true 时，通过键盘和鼠标进行的文本编辑被禁用，但
  仍可选择文本，也可通过编程方式编辑文本。
</SlintProperty>

### text

<SlintProperty propName="text" typeName="string" defaultValue='""' propertyVisibility="in-out">
正在编辑的文本
```slint 'text: "Initial text";'
LineEdit {
    text: "Initial text";
}
```
</SlintProperty>

## 函数

### focus()

调用此函数以聚焦 LineEdit 并使其接收后续键盘事件。

### clear-focus()

调用此函数以从此 `LineEdit` 移除键盘焦点（如果它当前具有焦点）。另请参见 <Link type="FocusHandling" />。

### set-selection-offsets(anchor: int, focus: int)

选择两个 UTF-8 偏移之间的文本：`anchor` 是保持不动的选择端，`focus` 是光标移动到的端，因此 `focus` 可以先于 `anchor` 以反向选择。
为两者传递相同的值可将文本光标放置在该偏移处而不选择任何内容。

### select-all()

选择所有文本。

### clear-selection()

清除选择。
无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

### copy()

将选中的文本复制到剪贴板。

### cut()

将选中的文本复制到剪贴板并从可编辑区域中移除。
无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

### paste()

将剪贴板的文本内容粘贴到光标位置。
无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

### undo()

撤销上次文本操作。
无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

### redo()

重做上次撤销的文本操作。
无论 `read-only` 和 `enabled` 属性如何，此函数都会生效。

## 回调

### accepted(string)

当按下回车键时调用。

```slint {2-4}
LineEdit {
    accepted(text) => {
        debug("Accepted: ", text);
    }
}
```

### edited(string)

当文本因用户修改而发生变化时发出

```slint {2-4}
LineEdit {
    edited(text) => {
        debug("Text edited: ", text);
    }
}
```

### key-pressed(KeyEvent) -> EventResult

当按键被按下时调用，参数是一个 <Link type="KeyEvent" /> 结构体。使用此回调在 `LineEdit`
处理键之前处理按键。返回 `accept` 表示你已处理该事件，或返回
`reject` 让 `LineEdit` 处理它。

### key-released(KeyEvent) -> EventResult

当按键被释放时调用，参数是一个 <Link type="KeyEvent" /> 结构体。使用此回调在 `LineEdit`
处理键之前处理按键。返回 `accept` 表示你已处理该事件，或返回
`reject` 让 `LineEdit` 处理它。
