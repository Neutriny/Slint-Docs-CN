---
title: 自定义鼠标光标
description: 实验性 `MouseCursor.custom()`：用图像设置自定义光标
---

除了内置形状之外，`mouse-cursor` 属性还接受用
`MouseCursor.custom(image, hotspot-x, hotspot-y)` 创建的自定义光标。

热点是图像中的一个点，以图像像素为单位从左上角算起，
它与实际指针位置对齐。它会被限制在图像边界内。

> **注意**：`MouseCursor.custom()` 是实验性的，可能会发生变化。
> 类型命名空间上的函数是带数据的枚举变体的替代形式；
> 一旦语言支持了这类变体，`custom` 应成为其中之一。

```slint
TouchArea {
    mouse-cursor: MouseCursor.custom(@image-url("cursor.png"), 0, 0);
}
```
