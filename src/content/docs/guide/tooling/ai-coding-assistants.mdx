使用 Slint skill 为你的 AI 编程助手提供针对 Slint 项目的专门指导。
该 skill 涵盖 `.slint` 语言、布局、常见陷阱、宿主语言互操作以及内置的 MCP 服务器。

插件和 skill 可从 [slint-ui/ai-plugins](https://github.com/slint-ui/ai-plugins) 仓库获取。

<Tabs syncKey="ai-tool">
  <TabItem label="Claude Code">
  从 GitHub 添加 Slint 市场并安装插件：

```sh
/plugin marketplace add slint-ui/ai-plugins
/plugin install slint@slint
```

之后 Claude Code 在处理 Slint 项目时就可以使用捆绑的 Slint skill。

  </TabItem>
  <TabItem label="Codex">
  在 Codex 提示符中输入以下内容，从 GitHub 安装该 skill：

```sh
codex plugin marketplace add slint-ui/ai-plugins
codex plugin add slint@slint
```

安装后重启 Codex，以便它加载新的 skill。

  </TabItem>
  <TabItem label="Antigravity">
  使用 [Antigravity CLI](https://antigravity.google/docs/cli/) 从 GitHub 安装插件：

```sh
agy plugin install https://github.com/slint-ui/ai-plugins
```

这会安装到 `~/.gemini/config/plugins/`，因此该插件在每个项目中都可用。
安装后重启 Antigravity，以便它加载新的 skill。

  </TabItem>
  <TabItem label="GitHub CLI">
  如果你已安装 [GitHub CLI](https://cli.github.com/)，`gh skill install` 可用于任何受支持的 agent —— 选择与你的工具匹配的那个：

```sh
# Codex
gh skill install slint-ui/ai-plugins slint --agent codex

# Claude Code
gh skill install slint-ui/ai-plugins slint --agent claude-code
```

查看 [`gh skill install`](https://cli.github.com/manual/gh_skill_install) 了解受支持 agent 的完整列表（Cursor、Gemini CLI、Windsurf 等）。之后重启你的 agent，以便它加载新的 skill。

  </TabItem>
  <TabItem label="npx skills">
  使用 [`skills`](https://github.com/vercel-labs/skills) CLI 将 Slint skill 安装到当前项目：

```sh
npx skills add slint-ui/ai-plugins --skill slint
```

这适用于 `skills` CLI 支持的任何 agent（Claude Code、Cursor 等），默认安装到项目的 agent skills 目录。传入 `-g` 可全局安装以供所有项目使用。

  </TabItem>
</Tabs>

## 你的助手能做什么

安装该 skill 后，助手在编写、调试和审查 `.slint` 代码时会遵循 Slint 的约定，并将 UI 连接到 Rust、C++、JavaScript 或 Python。
助手还会学习通过截取场景屏幕截图来验证渲染，然后再宣告工作完成。

该 skill 还会将助手连接到运行中的 Slint 应用程序内置的 Model Context Protocol (MCP) 服务器。
连接后，助手可以通过无障碍树检查 UI，使用鼠标、触摸和键盘输入来操作它，并截取屏幕截图以检查结果 —— 这一切都基于 Slint 现有的无障碍和测试 API，你的应用程序中无需任何调试钩子。
