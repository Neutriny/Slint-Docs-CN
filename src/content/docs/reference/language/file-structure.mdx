## Slint 源文件

`.slint` 源文件是零个或多个*顶层项*的序列，仅由空白和注释分隔。 \{#sls.file.source-file}

仅包含空白和注释的源文件格式良好，并且不定义任何组件。 \{#sls.file.source-file.empty}

## 顶层项

<OnlyInSC>
*顶层项*是*组件定义*、[结构体或枚举声明](../structs-and-enums/)、
[import 语句](../imports/)或[export 语句](../exports/)。 \{#sls.file.top-level-item}
</OnlyInSC>
</SC>

*顶层项*是组件定义、[import 语句](../imports/)、[export 语句](../exports/)、
[结构体或枚举声明](../structs-and-enums/)或[全局声明](../globals/)。

## 组件定义

组件定义具有以下两种形式之一： \{#sls.file.component.definition-forms}

```slint no-test
component Name { /* component body */ }
component Name inherits Base { /* component body */ }
```

`component` 关键字后面的标识符是组件的*名字*。 \{#sls.file.component.name}

第一种形式定义一个没有显式基类的组件；
第二种形式定义一个从 `Base` 命名的元素类型*继承*的组件。 \{#sls.file.component.inherits}

继承的组件会扩展其基类：
组件的实例是 `Base` 类型的元素。 \{#sls.file.component.inherits.meaning}

组件体的[绑定](../bindings/)应用于该元素，
而在组件体中实例化的元素会成为该元素的子元素。 \{#sls.file.component.inherits.body-applies}

除了其主体中[声明](../properties/)的那些属性外，该组件还具有 `Base` 的属性，
组件体中的绑定可以绑定它们。 \{#sls.file.component.inherits.properties}

标识符 `Base` 应解析为内置元素、文件中先前定义的组件或[导入的](../imports/)组件。 \{#sls.file.component.inherits.base}

花括号 `{` 和 `}` 界定*组件体*。 \{#sls.file.component.body-braces}

## 组件体

组件体是零个或多个*元素实例化*、[绑定](../bindings/)和[属性声明](../properties/)的序列，仅由空白和注释分隔。 \{#sls.file.component.body}

不包含任何元素实例化的组件体格式良好。 \{#sls.file.component.body.empty}

## 元素实例化

元素实例化具有以下形式： \{#sls.file.element.instantiation-form}

```slint no-test
TypeName { /* element body */ }
```

标识符 `TypeName` 应解析为内置或用户定义的组件。 \{#sls.file.element.instantiation-typename}

实例化前可以带有一个 _id_ 和 `:=`，例如 `foo := Rectangle { }`，
在组件内命名该元素，
以便[引用](../expressions/#references)能够访问其属性。 \{#sls.file.element.id}

```slint
export component Example inherits Window {
    frame := Rectangle {
        background: #2a6e3f;
        width: 120px;
    }
    Rectangle {
        background: #1a4f2c;
        width: frame.width;
    }
}
```

id 是一个[标识符](../lexical-structure/#sls.lex.identifier.classes)，
因此当两个 id 的
[规范化形式](../lexical-structure/#sls.lex.identifier.normalization)相等时，它们是同一个 id。 \{#sls.file.element.id.identifier}

id 在组件内应唯一。 \{#sls.file.element.id.unique}

<NotInSC>唯一性规则涵盖整个组件，包括 `for` 和 `if` 子树内的元素。</NotInSC>

名字 `self`、`parent` 和 `root` 是保留的，不得用作 id。 \{#sls.file.element.id.reserved}

<OnlyInSC>
`Window` 以及直接或间接继承 `Window` 的组件都不得作为元素实例化。 \{#sls.file.element.no-window-instantiation}
</OnlyInSC>
</SC>

将 `Window` 或继承 `Window` 的组件作为元素实例化已废弃：
它不会创建单独的窗口。

<SC>
花括号界定*元素体*。
元素体是零个或多个嵌套元素实例化和[绑定](../bindings/)的序列，仅由空白和注释分隔。 \{#sls.file.element.body}

嵌套的元素实例化是它所在元素体对应元素实例化的*子元素*。
子元素关系构成一棵树，其根为直接出现在组件体中的元素。 \{#sls.file.element.tree}

## 示例

下面是一个完整、格式良好的 `.slint` 源文件： \{#sls.file.example.intro}

```slint
export component Hello inherits Window {
    Rectangle {
    }
    Rectangle {
    }
}
```

它导出一个组件 `Hello`，该组件继承自 `Window`，其主体包含两个顶层 `Rectangle` 实例化。 \{#sls.file.example.description}
